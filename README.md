# Cuentas en pareja

Calculadora de gastos compartidos al 50 % con liquidación por categorías y una única transferencia final.
Es una página estática: no necesita servidor ni base de datos. Los datos se guardan en el propio navegador.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `cuentas`). Debe ser público en una cuenta gratuita.
2. Sube **todos los archivos de esta carpeta a la raíz** del repositorio (sin meterlos en una subcarpeta):
   `index.html`, `manifest.webmanifest`, `favicon.ico`, `icon-192.png`, `icon-512.png`,
   `icon-maskable-512.png`, `apple-touch-icon.png` y este `README.md`.
3. Ve a **Settings → Pages**. En *Build and deployment* elige **Deploy from a branch**,
   rama **main** y carpeta **/ (root)**, y guarda.
4. En uno o dos minutos la página estará en `https://TU-USUARIO.github.io/cuentas/`.

## Instalar en el iPhone

1. Abre el enlace en **Safari**.
2. Compartir → **Añadir a pantalla de inicio**.
3. Usa siempre el icono de la pantalla de inicio: su almacenamiento es independiente del de Safari.

## Datos

- Todo se guarda en el navegador del dispositivo. Haz una copia de vez en cuando desde **Ajustes → Copiar copia** y guárdala en tus notas.
- Para pasar datos de otra versión: copia la copia de seguridad allí y pégala en **Ajustes → Restaurar** aquí.

## Actualizar la página

Sustituye `index.html` en el repositorio (Add file → Upload files). Los datos guardados no se tocan.
Si cambias los iconos, borra la app de la pantalla de inicio y vuelve a añadirla: iOS guarda el icono antiguo.
